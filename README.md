# Cyber Buddy

Cyber Buddy is a C# console and Windows Forms application designed as a cybersecurity awareness chatbot. It helps users learn about cybersecurity topics like phishing, password safety, safe browsing, and more through interactive conversations and quizzes.

---

## Features

- Conversational chatbot interface with multiple cybersecurity topics  
- Quiz functionality to test user knowledge  
- Text-to-speech support for accessibility  
- Activity logging for user interactions  
- Modular design for easy expansion and maintenance
